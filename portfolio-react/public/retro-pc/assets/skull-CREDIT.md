# ASCII skull wallpaper

Skull geometry by Vladimir Petkovic, released under CC0 1.0 Universal.
Source: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/ScatteringSkull
License: https://creativecommons.org/publicdomain/zero/1.0/

The source model was converted in Blender into 49 views of lighting samples.
The website draws these samples as ASCII characters; the large source model
is not downloaded by the viewer or included in the PC model. The exported PC
screen contains a still of this derived ASCII artwork.

Rebuild with scripts/bake_ascii_skull.py through Blender MCP. Source SHA-256:
